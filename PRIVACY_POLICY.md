# Privacy Policy

Effective date: October 11, 2026

Beacon is a file sharing app that helps you transfer files directly between your own devices on the same local network.

## Summary

Beacon does not collect, track, sell, or share personal data. The app does not use analytics, advertising, subscriptions, in-app purchases, or remote servers.

## Files

Beacon only transfers files that you explicitly choose to send. Files are transferred directly from one device to another over your local network. They are not uploaded to Beacon servers, and Beacon does not keep a copy of files you send.

When your device receives a file, Beacon saves that file locally on your device. Depending on the platform, received files may be saved in a Beacon folder under Downloads, in the app's Documents folder, or through the platform's media storage system.

## Local Network Discovery

Beacon uses local network discovery so nearby Beacon devices can find each other. While the app is running, it advertises a local network service on your network. That advertisement includes:

- A device name, taken from the name your system reports. On Android this is the device name you set in system settings, on iOS the device name or model, and on computers the computer name. It may therefore include a name you chose yourself, such as "Jon's Phone".
- A device identifier that stays the same between app launches, so other Beacon devices recognise your device as the same one each time instead of listing it repeatedly.
- The IP address and connection port your device is reachable at.

Anything on your local network that looks for these advertisements can see this information, not only Beacon. This is how local network discovery works on every platform, and it is the same information other devices need in order to send you a file.

This discovery is limited to the local network. Beacon does not send this information to a remote server.

## Device Information

Beacon reads basic device information to build the device name and identifier described above. This may include the device name your system reports, the device model, the hostname, the operating system name, or a platform device identifier such as the vendor identifier on iOS.

Beacon uses this information only to identify your device during local discovery, as described in that section. It is not sent to a remote server, and Beacon keeps no record of it beyond the running app.

## App Preferences

Beacon stores app preferences locally on your device, such as selected language and theme. These preferences are not sent to any remote server.

## Permissions

Beacon may request or use the following permissions or capabilities:

- Local network access: used to discover nearby Beacon devices and transfer files directly.
- File or photo library access: used only when you choose files, photos, or videos to send.
- Network client/server access: used to send and receive files between devices on the same local network.
- Wi-Fi or multicast access on Android: used for local network discovery.

## Third-Party Services

Beacon does not use third-party analytics, advertising networks, tracking SDKs, or cloud storage services.

## Data Sharing

Beacon does not sell, rent, or share personal data with third parties. File contents are sent only to the receiving device you select.

## Children

Beacon is not designed to collect information from children. The app does not include accounts, advertising, tracking, messaging, or public user-generated content.

## Security

Transfers rely on your local network. You should only use Beacon on networks and with devices that you trust. Beacon does not intentionally modify or damage your files, but we recommend you to keep backups of important files.

## Changes

This policy may be updated if Beacon's behavior changes. Any future changes should continue to describe the app's actual data handling practices.

## Contact

For privacy questions, contact the developer using the support contact listed on Beacon's App Store product page.
